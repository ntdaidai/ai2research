# ai2research 研究工作台

轻量 HTML/CSS/JS，无构建步骤、CDN、在线字体或前端依赖。页面分六个独立视图，桌面使用左侧导航，手机使用紧凑导航；支持地址直达、刷新与浏览器返回：

- 工作台：辅助科研与全流程科研（AutoSearch）两个入口，以及调研、实现、产出三个工具阶段入口。
- 辅助科研：工具选配、idea 与干预输入、人工确认点，以及 Agent 任务文档生成。
- 全流程科研：当前项目状态、完成环节、实验计数与最近动态。
- 研究进度：从选题到交付的 12 个环节，以及完成依据、相关材料与下一步。
- 成果：论文、结构图、实验图表与逐次实验记录。
- 工具与资料：参考论文 PDF、GitHub 地址和版本，以及 Skill、MCP、插件、执行与模型清单。

工具卡片展示名称、简介、用途与来源链接；根据用户要求，不展示工具的检测、接入或可用性状态。

## 辅助科研

访问 `/#assist`，可先选领域和“还没有idea / 已经有idea / 已经有结果”起点，使用预设工具组合，再按阶段、类型、领域或关键词调整。预设保留已有文字与工具选择。当前目录共111项：77项工具、应用、MCP、Skill及实验工具包，34项论文、代码、模型与数据入口；包含现有14项工具清单、3个项目工具包，以及94项公共目录条目。工具包引用已有CLI/MCP入口。支持添加自己的工具名称、简介、类型和文档链接。

公共目录单独维护在 `catalog.js`，由实时服务白名单与静态导出共同提供。九个领域是通用科研、计算机视觉、自然语言处理、大模型与多模态、联邦与隐私计算、系统与分布式、强化学习与机器人、数据科学与图学习、生命科学。通用入口也出现在各专业领域筛选结果中。辅助页每次展示12项，可继续加载；工具目录每次展示18项。两处默认按调研阶段浏览，可切换实现、产出或全部。类型、领域和搜索用于进一步收敛。卡片保留名称、简介、类型与来源，不显示内部ID、重复阶段标签和工具检测状态。

工具与资料页分“参考论文与代码 / 工具目录 / 论文与开源入口”三个页签，最后一项独立按领域与关键词筛选，可直接把资源加入个人工具链。

七环节为调研、筛选、跑实验、迭代、出图、出稿、润色，可从任一环节开始。默认在筛选、跑实验、出稿前人工确认；确认要求写入文档，由接收文档的Agent执行。填写“本轮干预”后重新生成文档，即可在已有研究中加入新idea或修改要求。

生成的 `AGENT_TASK.md` 包含idea、材料、研究领域、资源边界、人工干预、工具来源与调用要求、执行顺序、确认点与预期交付。支持预览、复制和下载；剪贴板受限时选中全文供手动复制。草稿及自定义工具仅保存于当前浏览器localStorage，不写研究状态库或跨设备同步。默认独立任务；勾选关联项目后才显示项目选择器并附带项目上下文，已暂停项目在文档中继续保留暂停约束。

网页提供选配与交接，执行仍在研究对话；没有安装工具、连接Agent或提交实验。工具卡片和任务文档不展示接入检测状态。今晚演示可点击“填入示例”，示例明确标为尚未执行。

首页只展示两种模式、七环节路径和三个阶段入口。执行范围与补充干预收进详情，关键字段、工具选配和人工确认保留；关联项目及项目参考资料视图才显示项目选择器；使用帮助只有一个入口。支持手机布局、键盘操作、减少动态效果设置和研究指令复制，复制失败时显示可选文字。

## 服务器静态部署

导出研究记录与当前已核验的论文、图表，再以用户级服务提供静态文件：

```bash
.venv/bin/python tools/export_showcase_static.py
.venv/bin/python tools/deploy_showcase.py --host SERVER_IP --port 8765 --static-directory .local/showcase-static
```

浏览器访问 `http://SERVER_IP:8765/`。服务独立于 SSH 会话，异常退出自动重启。只提供静态前端，无研究后端；研究进展变化后重新运行导出命令，再刷新页面。页脚显示快照导出时间，切换项目时读取该项目的静态快照。

部署地址由使用者选择；本机默认 `http://127.0.0.1:8765/`。Linux 用户服务名为 `ai2research-showcase.service`，配置入口在 `.local/showcase-server/server.json`。

## 本机实时查看

```bash
./ai2research showcase
./ai2research showcase --host SERVER_IP --port 8765
```

默认仅本机 `127.0.0.1:8765`；指定服务器网卡地址后可同网段访问。实时模式每 30 秒读取已保存的记录，静态部署每 30 秒重新读取导出的快照。打开说明弹窗时暂缓刷新。读取失败保留上次数据并提示。

展示服务以 SQLite `mode=ro` 读取一致快照，不经过写维护状态的 service 包装，不调用模型或提交实验，不改变暂停状态。空状态库不初始化项目。

## 进度与证据

12 个环节分别为选题入口、文章筛选、代码核查、可行课题、实验准备、实验运行、复核消融、实验审查、论文初稿、图表制作、稿件审查、成果交付。按已有证据计数，不预测剩余时间，不把运行预算上限当成必做次数。

实验准备以有效任务交接，或已核实的正式双审及交付验收作为完成依据。后一情况要求已有冻结方案、批准和成功回收结果，且正式归档及其当前文件摘要一致。历史任务交接缺项仍在阶段说明中展示，原任务板保持原状态。仅有实验结果或正面评语不足以替代正式验收；新审查或交付文件变化后重新展示待核对。

审查显示当前轮次的意见与验收，高分不清除重大问题。参考资料来自摘要匹配的已登记清单；工具清单区分文件存在、配置登记和实际可用性，不读取密钥或发起付费调用。

成果提供当前登记且摘要一致的 `manuscript_pdf`、`diagram_pdf`、`figure_png`、`figure_pdf`，每类一个；正式稿件验收后标为“论文终稿”。拒绝旧版本、修改文件、跨项目路径和符号链接。实时服务资源采用白名单。普通输出最多 32 MiB；正式归档采用流式摘要校验（归档最多 128 MiB、成员最多 32 MiB、累计最多 128 MiB），不解压或执行。

## 验证

```bash
.venv/bin/python -B -m unittest tests.test_showcase tests.test_progress tests.test_showcase_catalog -q
```

可选真实浏览器检查使用 Node 24 WebSocket 与 Firefox WebDriver BiDi，无 npm 依赖。创建临时 profile 后启动：

```bash
firefox --headless --no-remote --profile /absolute/path/to/temporary-profile --remote-debugging-port 9222 about:blank
SHOWCASE_URL=http://SERVER_IP:8765/ node tests/showcase_browser.mjs
```

验证六页路由、刷新/返回、工具选配/自定义/草稿恢复、文档内容与下载Blob、人工干预与中途接续、暂停保护、原有完成依据/成果SHA256/参考资料，三个新手预设、领域资源筛选、目录渐进加载、无工具可用性标签，以及1440/390/320布局。浏览器检查必须使用专用临时profile，会初始化本功能草稿。可用 `SHOWCASE_OUTPUT=research/showcase/assisted-20261123` 指定截图与回执目录。`SHOWCASE_CAPTURE=viewport`生成适合PPT使用的首屏截图；`BROWSER_BIDI_URL`可指定隔离调试端口；仅检查本轮改动时可用`SHOWCASE_SKIP_AUTO_REFRESH=1`跳过未修改的30秒定时同步等待。完成后关闭临时浏览器并删除profile；保留正式静态服务。
