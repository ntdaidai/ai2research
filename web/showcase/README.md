# ai2research 轻量展示台

```bash
./ai2research showcase
./ai2research showcase --project cv-20261118 --port 8765
```

在运行该命令的电脑打开 `http://127.0.0.1:8765`，Ctrl+C 关闭。远程机器使用 SSH 转发，例如 `ssh -L 8765:127.0.0.1:8765 your-server`，随后在自己的电脑打开相同地址。默认仅监听本机；这是单用户本地展示入口。

同一局域网访问时，绑定服务器网卡地址即可，无需 SSH 端口转发：

```bash
./ai2research showcase --host SERVER_IP --port 8765
# 在自己的电脑打开 http://SERVER_IP:8765/
```


原生 HTML/CSS/JS，后端使用 Python 标准库，无构建步骤、CDN、在线字体、前端依赖或额外数据库。页面资源约 86 KB；使用项目现有 Python 环境即可。状态目录沿用 `harness.toml` / `RESEARCH_STATE_DIR`，不包含硬编码课题数据。

页面采用明亮的白色/雾蓝配色，原生SVG插画、实际进度环与实验状态分布图呈现研究过程；没有外部动效库或图片依赖。12环节分为发现方向、实验验证、形成成果三组，主页面可以一键定位当前环节。

首次使用可打开指南，按“选项目、看进度、找下一步”上手；“复制继续研究指令”将当前项目和下一步整理成可粘贴到研究对话的文字，不在网页里执行。浏览器无法直接复制时提供可选文字框；暂停项目生成的指令明确保留暂停状态。空项目提供开始研究的指令模板。

页面以完整研究进度为中心：选题入口、文章筛选、代码核查、可行课题、实验准备、实验运行、复核消融、实验审查、论文初稿、图表制作、稿件审查、成果交付。每个环节显示状态；点击后查看完成条件、实际数量、缺项和下一步。文章和代码环节可查看候选论文与固定版本仓库。实验先显示由真实数量生成的状态分布图，逐次记录默认折叠，另保留论文/图表入口，支持切换项目、手动刷新、全屏与手机布局。页面可见且没有打开说明弹窗时，每30秒自动同步本地记录；任意说明/指南弹窗打开时暂缓刷新。动效仅呈现流程与实际数值变化，系统启用减少动态效果时，浮动插画、连线、进度环和图表都保持静止。

“工具与研究资料”栏目提供两个标签页：

- **参考论文与代码**：随项目切换，读取已登记且摘要匹配的选题参考清单。列出论文标题、发表信息、代码许可、固定提交版本，以及 PDF/原文、GitHub 和发表页面；GitHub 克隆地址转为网页地址。清单尚未登记或已变化时明确提示。
- **当前工具**：按 Skill、MCP、插件、执行与模型筛选，分别显示技能文件、MCP 配置登记、插件技能包、可执行入口和模型配置。检测结果不等于网络连接或运行验收；不读取密钥、不发起付费请求。无项目时仍可查看本机工具。

正文使用系统中英文字体，统计数字使用等宽数字；普通辅助文字最小12px。长文件名可截断，但大小独立保留，完整名称可通过悬停查看。

展示服务直接以 SQLite `mode=ro` 读取一个一致快照，不经过会更新维护状态的 service 包装，不远程轮询、调用模型、提交实验或改变暂停状态。空状态库不初始化项目；读取失败保留上次显示并明确标识。文件数按路径去重，历史登记修订不重复累计。

进度条统计已满足完成条件的环节数，不预测剩余时间，也不使用试验预算上限作为必做次数。阶段可并行、有返工；初稿和图表已经产出时，即使实验审查未通过，也分别显示其真实进展。任务交接、成功作业回收和当前文档SHA联合判定；有实验而准备任务未交接时显示“待核对”，不修改原任务板。评审意见收齐与当前版本正式验收分别呈现，较高评分不清除重大问题，新审查轮次不继承旧意见。正式验收通过只从真实、未变化的最终交付归档及其工作流验收记录确认，不将正面文本意见直接视为交付通过。

成果入口仅提供当前登记的 `manuscript_pdf`、`diagram_pdf`、`figure_png`、`figure_pdf`，每类精选一个。打开时检查项目边界、普通文件及 SHA256；旧版本、被修改文件和符号链接不提供下载。页面静态资源使用固定白名单，不暴露项目目录。32 MiB 是单个展示文件的大小上限，不影响原有交付工具。

后续源码打包会包含 `web/`；此展示台不代替完整研究状态备份、迁移或科研验收。

## 验证

后端回归使用项目 Python 环境：

```bash
.venv/bin/python -B -m unittest tests.test_showcase tests.test_progress tests.test_showcase_catalog -v
```

可选浏览器回归使用 Node 24 自带的 WebSocket 和 Firefox WebDriver BiDi，不使用 npm 包。在展示服务运行时，另启 Firefox 的隔离临时 profile：

```bash
firefox --headless --no-remote --profile /absolute/path/to/temporary-profile --remote-debugging-port 9222 about:blank
node tests/showcase_browser.mjs
```

先创建临时 profile 目录；验证结束关闭该浏览器并删除临时 profile。测试读取真实项目，不提交实验；检查浅色主题、12环节/三组进程、真实进度环和分布图、首次使用/当前环节入口、复制反馈与失败兜底、空项目模板、暂停保护、刷新恢复、自动同步、成果 SHA 和桌面/手机布局，并将截图与回执保存到 `research/showcase/`。

可选减少动效验证：在另一个临时Firefox profile的`user.js`中设置`user_pref("ui.prefersReducedMotion", 1);`，用9223端口启动该隔离浏览器，再运行`node tests/showcase_motion.mjs`。验证结束关闭此浏览器并删除该临时profile；它不修改用户浏览器或系统设置。

正式交付包校验采用流式摘要，独立于普通文档读取预算；单归档最多128MiB，单个交付文件最多32MiB、累计最多128MiB。不会解压归档或执行其中代码。图表、稿件审查及最终交付按归档内已有验收记录和当前文件一致性展示；旧准备任务仍需按真实工作补交接，不自动更改任务板。
