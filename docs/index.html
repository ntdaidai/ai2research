    使用帮助

    辅助科研：填写 idea，按调研、实现、产出选择工具，设置人工确认点，生成并复制任务文档，或下载 Markdown 添加给 Agent。草稿保存在当前浏览器，可以随时补充本轮干预后重新导出。

    全流程科研：在顶部切换已有项目，查看状态、研究进度和成果。需要继续时复制研究指令，粘贴到研究对话。工具与资料页保留当前项目的论文、代码与工具目录。

    进度统计说明

    12 个环节按完成依据计数；有效的正式双审与交付验收可确认实验准备完成，历史任务交接缺项保留在阶段说明中。初稿、图表和审查可以分别推进；总进度不代表剩余时间或论文质量。

    “待核对”表示记录或材料需要确认；“待修订”表示本轮审查仍有问题。点击节点，就能看到具体缺项与下一步。

    页面可见时每30秒同步，也可以立即刷新。它读取已保存的研究记录，复制指令后仍需在研究对话中执行。

    工作台只读项目记录，不在这里启动实验或改变暂停状态。
