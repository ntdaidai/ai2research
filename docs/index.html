    未能直接复制，请选择下方文字，用键盘或长按复制。
    UNDERSTANDING PROGRESS

    进度来自真实的研究记录。

    12个环节按各自的完成条件计数。初稿、图表和审查可以分别推进；总进度不代表剩余时间或论文质量。

    “待核对”表示记录或材料需要确认；“待修订”表示本轮审查仍有问题。点击节点，就能看到具体缺项与下一步。

    页面可见时每30秒同步，也可以立即刷新。它读取已保存的研究记录，复制指令后仍需在研究对话中执行。

    工作台只读项目记录，不在这里启动实验或改变暂停状态。
